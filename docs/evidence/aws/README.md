# AWS Evidence Mapping

このディレクトリは、ユーザーがマスキング済みとして用意したAWSハンズオンの証跡画像を、
READMEから参照しやすい英数字ファイル名へコピーしたものです。

GitHub公開前に、最終確認として次の情報が残っていないか目視確認してください。

- AWS Account ID
- Access Key / Secret Access Key
- パスワード / JWT Key
- MFA QR / Secret
- SSH秘密鍵
- Public IP / DNS
- RDS Endpoint
- ARN
- Instance / VPC / Subnet / Security Group ID
- ローカルPCのユーザー名や個人パス

元画像はリポジトリ外に保管し、公開用にはこのフォルダのマスキング済み画像のみを使用してください。
